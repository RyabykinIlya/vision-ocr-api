# vision-ocr

Локальный сервис `vision-ocr-api` — FastAPI поверх Ollama vision-модели
(`qwen2.5vl:7b-q4_K_M` на GPU). Принимает изображение, возвращает текст.

## Где он живёт

`VISION_OCR_URL` из окружения, по умолчанию `http://localhost:8080`.
Сервис поднимается в WSL через docker compose; если `curl $VISION_OCR_URL/health`
не отвечает — не выдумывай результат, скажи, что сервис недоступен, и предложи
`docker compose up -d` в каталоге репозитория.

Проверка одной командой:

```sh
curl -fsS "${VISION_OCR_URL:-http://localhost:8080}/health"
# {"status":"ok","ollama":true,"model":"qwen2.5vl:7b-q4_K_M"}
```

## Как вызывать

Мультипарт, один файл:

```sh
curl -sS -X POST "${VISION_OCR_URL:-http://localhost:8080}/v1/recognize" \
  -F "files=@/path/to/image.png" \
  -F "preset=ocr" | jq -r .text
```

Несколько файлов (страницы одного документа) — тем же запросом, `-F files=@` на каждый.

Base64 через JSON, если файл уже в памяти:

```sh
B64=$(base64 -w0 image.png)
curl -sS -X POST "$URL/v1/recognize/base64" \
  -H 'Content-Type: application/json' \
  -d "{\"images\":[\"$B64\"],\"preset\":\"ocr\"}" | jq -r .text
```

## Пресеты

| preset | Когда |
|---|---|
| `ocr` | По умолчанию: дословно, структура сохранена, без комментариев |
| `ocr_translate` | Нужен перевод распознанного на русский |
| `describe` | «Что на картинке» — описание на русском |
| `table` | Только таблицы в markdown |
| `diagram` | Разбор графика/схемы на русском |

Нужна другая формулировка — `"prompt": "..."` вместо `preset` (одновременно
нельзя, вернётся 422).

## Что вернуть пользователю

`text` из ответа, как есть. Если `text` == `NO_TEXT_FOUND` — текста на
изображении нет, так и скажи, не додумывай. При `NO_TABLE_FOUND` — таблицы нет.

Метаданные (`model`, `elapsed_ms`) нужны только если пользователь спрашивает
про скорость или качество.

## Ограничения

- 25 МБ на файл, до 8 изображений в запросе, `422` при превышении.
- `413` — файл слишком большой, `502` — Ollama недоступна (её текст ошибки
  приходит в `detail`, покажи его).
- Первый вызов после простоя грузит модель в VRAM — до 30 с. Дальше 3–10 с
  на ответ у 7B. Не считай долгий первый ответ поломкой.
- Форматы: PNG, JPEG, WebP, BMP, GIF (первый кадр), TIFF. Не PDF и не HEIC —
  для PDF сначала сконвертируй страницы в PNG.
