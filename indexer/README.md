# indexer — ночной индексатор фотоархива

Отдельное приложение: обходит медиатеку, прогоняет каждое новое/изменившееся
изображение через `vision-ocr-api` с несколькими промптами и складывает
результаты в SQLite с полнотекстовым индексом (FTS5). С основным API его
объединяет только `docker-compose.yml` на уровне репозитория.

## Как это работает

- Один проход по дереву `INDEXER_MEDIA_DIR` (в контейнере `/media`, read-only).
  Новые и изменившиеся файлы (mtime+size) становятся очередью.
- На каждую картинку — по запросу на каждый промпт из `INDEXER_PROMPTS`
  (по умолчанию `scene,objects`; можно добавить `text`). Ответы хранятся как есть.
- Падения из-за бага Ollama «token repeat limit reached» чинит сам
  vision-ocr-api (выгрузка модели + ретрай). Если промпт всё же не удался,
  индексатор пробует `INDEXER_FALLBACK_MODEL` (по умолчанию 7b), и только
  потом помечает картинку `failed`.
- Работает только внутри окна `INDEXER_WINDOW` (по умолчанию 00:00–07:00,
  Europe/Moscow). Окно закрылось — дописывает текущую картинку и засыпает
  до следующей ночи. Всё переживает рестарты: очередь — это сама БД.
- Результат: `indexer/data/index.db` (SQLite, WAL). Бэкап = скопировать файл.

## Поиск

```sh
# из любого места, где есть python3 и файл БД:
python3 indexer/search.py кошк*              # префикс: найдёт кошка/кошки/кошкой
python3 indexer/search.py рецепт --full      # с полным текстом описания
python3 indexer/search.py море --prompt scene
python3 indexer/search.py --stats

# или через контейнер:
docker compose run --rm indexer python search.py кошк*
```

Слова без `*` автоматически получают префиксную звёздочку (морфология по-русски
покрывается префиксом). Путь в выдаче — относительно корня медиатеки, т.е.
`Soch/IMG_xxx.jpg` = `D:\home_share\медиа\Soch\IMG_xxx.jpg`.

## Включение ночной работы

1. Проверить в `.env`: `INDEXER_ENABLED=true`, путь `INDEXER_MEDIA_HOST`.
2. `docker compose up -d --build indexer`
3. Контейнер живёт постоянно, но трогает GPU только в окне 00:00–07:00.
   Выключить: `INDEXER_ENABLED=false` + `docker compose up -d indexer`.

## Ручные прогоны (вне окна)

```sh
# пробная партия из 12 случайных картинок в чистую БД:
docker compose run --rm indexer python indexer.py --once --limit 12 --fresh --sample 42

# переиндексировать упавшие:
docker compose run --rm indexer python indexer.py --once --retry-failed
```

## Бюджет

~70k изображений, 2 промпта, ~6–8 с на запрос на qwen2.5vl:3b (GPU):
~1000–1500 картинок за ночь → полный первичный проход ориентировочно
1,5–2 месяца ночей. Ускорить можно промптом покороче, одним `scene`
или окном подлиннее. Дальше — только инкремент (минуты за ночь).
